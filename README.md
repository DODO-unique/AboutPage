# Gaurav Mali — Portfolio

A React and TypeScript portfolio built with Vite.

## Requirements

- Node.js
- npm

## Development

```sh
npm ci
npm run dev
```

## Checks and production build

```sh
npm run lint
npm run build
npm run preview
```

The production build is written to `dist/`. Deploy the contents of that directory to a static host. If the site is hosted below the domain root, configure Vite's `base` option to match the deployment path.
